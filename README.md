# AI Agent Project 🤖🚀

An intelligent AI Agent application running locally inside **Termux on Android**, powered by Python.

## 📂 Project Structure
- **app.py**: Core application entry point.
- **chat.py**: AI conversation logic.
- **save_chat.py**: Chat history persistence.
- **static/**: Static assets (CSS/JS).
- **templates/**: HTML templates for web interface.

## 🛠️ Features
- Runs completely inside Android Termux.
- Executes shell commands dynamically.
- File management and manipulation support.
- Interactive web/chat interface.

## ⚙️ Setup
1. `git clone https://github.com/tusharsharmalogic-cmyk/Ai-agent.git`
2. `pip install -r requirements.txt`
3. `python app.py`
